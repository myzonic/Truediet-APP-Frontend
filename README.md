# True Diet welcome screen

React Native / Expo front end recreated from the supplied welcome-screen SVG.

## Run it

Install Node.js (which includes npm), then run:

```bash
npm install
npm start
```

Use `npm run android`, `npm run ios`, or `npm run web` to open a specific target.

The original design is bundled at `assets/welcome-screen.svg`; `App.js` renders it responsively and exposes the original Get Started control as an accessible native button.
